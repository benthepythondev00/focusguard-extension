# FocusGuard - Pomodoro Timer & Break Reminder

A modern Chrome extension that helps you stay productive with smart Pomodoro sessions, break reminders, and focus tracking.

## Features

### Free Tier
- 8 focus sessions per day
- Pomodoro timer (25/5/15 min defaults)
- Break reminders with notifications
- Session tracking
- Light/Dark/System themes
- Customizable durations

### Pro Tier ($9.99 one-time)
- Unlimited focus sessions
- Detailed weekly statistics
- Priority support

## Installation

### From Chrome Web Store
1. Visit the [Chrome Web Store](https://chrome.google.com/webstore/detail/focusguard)
2. Click "Add to Chrome"
3. Click the FocusGuard icon to start your first session

### Development
```bash
# Install dependencies
pnpm install

# Development mode
pnpm dev

# Build for production
pnpm build

# Create ZIP for Chrome Web Store
pnpm zip
```

## How It Works

1. Click the FocusGuard icon in your toolbar
2. Press Start to begin a 25-minute focus session
3. Work without distractions until the timer ends
4. Take a 5-minute break (or 15 minutes after 4 sessions)
5. Repeat and watch your productivity soar
